# Ledger Co – React Dashboard

React + Vite frontend for the Ledger Co API: dashboard, loan list, loan details, create loan, payment history and balance check.

```bash
npm install
npm run dev   # http://localhost:5173, proxies /api to the backend on :8080
```

For a deployed build, set `VITE_API_URL` to the backend origin (see `.env.example`).
